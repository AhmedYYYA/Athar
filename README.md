# ATHAR | أثر

**Agency · Transformation · Honing · Artificial Intelligence · Readiness**

ATHAR is a UAE-born, child-safe AI literacy and readiness experience for children aged 7–12, families and educators.

> The child remains the thinker. AI remains the tool.

https://ahmedyyya.github.io/Athar/

## Product demonstration

The v3 site includes responsive desktop/tablet/mobile layouts, English/LTR and Arabic/RTL switching, the Explore → Learn → Create → Impact journey, SUPER learning method, Safety Passport and Skills Passport framing, child/parent/educator role views, progress and cohort indicators, and an interactive verification mission.

## Structure

- `index.html` — v3 semantic application shell
- `styles.css` — v3 ATHAR design system and responsive layouts
- `app.js` — bilingual product state, role switching and mission interaction
- `manifest.webmanifest` — PWA metadata bound to the approved ATHAR symbol
- `assets/brand/` — controlled ATHAR production identity assets

## Safety boundary

This remains a controlled front-end product demonstration. It does not connect directly to an AI provider, collect real child data, implement production authentication, process payments, expose open-web retrieval or provide an unrestricted child chatbot.

Production engineering should add secure authentication, consent and child profiles, server-side mission/content services, Safety/Skills Passport persistence, adult controls, AI gateway integration, telemetry, security testing and pilot release controls.
