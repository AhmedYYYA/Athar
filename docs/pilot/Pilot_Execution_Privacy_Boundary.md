# ATHAR | أثر — Pilot Privacy & Storage Boundary

The public ATHAR repository contains blank schemas and operating guidance only. It is **not** the approved store for completed participant records.

Before launch, the operator must decide:
- approved storage location;
- authorized users/roles;
- retention/deletion period;
- participant-code linkage handling;
- transfer/export rules;
- incident response for unauthorized access;
- whether any institutional/privacy notice is required.

ATHAR's current website stores bounded learning state locally in the browser. This does not replace the operator's governance for observation/session records collected outside the website.

Do not introduce cloud spreadsheets, analytics or third-party form tools for child pilot data merely for convenience without explicit approval under the pilot governance.
