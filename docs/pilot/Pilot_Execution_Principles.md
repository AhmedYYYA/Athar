# ATHAR | أثر — Pilot Execution Principles

1. **Child agency first.** Facilitation must not become answer-giving.
2. **Safety outranks completion.** A stopped session is preferable to unsafe or distressed continuation.
3. **Supported is not failed.** Hint use is a learning signal, not a negative label.
4. **Minimum necessary data.** Collect only what the pilot question requires.
5. **Evidence over anecdotes.** Record structured observations while preserving important qualitative context without unnecessary personal detail.
6. **Arabic is first-class.** Analyze language parity rather than assuming translation equivalence.
7. **Age bands are meaningful.** Do not silently pool 7–9 and 10–12 when experience differs.
8. **Defects are not pedagogy.** Separate interface/technical failures from learning findings.
9. **Baseline integrity matters.** Material changes create a new comparison boundary.
10. **Pilot is not production.** Do not infer production readiness from bounded supervised operation without closing the production gap register.
