# أثر | ATHAR — اقرأ هذا أولاً قبل تنفيذ التجربة

إذا كنت تستعد لاستخدام أثر مع الأطفال، **لا تبدأ بسجل الجلسات**.

1. اقرأ بروتوكول التجربة المعتمد.
2. أكمل قائمة جاهزية التنفيذ.
3. أغلق متطلبات الحوكمة الفعلية مع الجهة المشغلة/المؤسسة.
4. عيّن المسؤوليات والأدوار.
5. ثبّت واختبر نسخة الموقع المحددة برمز الالتزام (SHA).
6. نفّذ فحص الموقع/الأجهزة وتمرين التصعيد الافتراضي.
7. قم بإحاطة الميسّرين والتحقق من جاهزيتهم.
8. نفّذ التجربة التمهيدية التشغيلية تحت الإشراف.
9. بعد اجتياز بوابة التجربة التمهيدية فقط، أكمل سجل قرار إطلاق التجربة.
10. بعدها تُنفذ الجلسات المحددة وفق دليل التشغيل.

**جاهزية المستودع لا تعني تلقائياً التصريح ببدء تجربة الأطفال.**
