# أثر | ATHAR — القواعد الحرجة لتنفيذ التجربة

1. لا جلسة حقيقية مع طفل دون استكمال شروط المشاركة المعتمدة وموافقة الطفل.
2. لا بيانات حقيقية للمشاركين في مستودع GitHub العام.
3. لا إطلاق للمجموعة مع وجود مشكلة حرجة S3 مفتوحة.
4. لا تغيير صامت لخط أساس المنتج.
5. لا إعطاء للإجابة تحت مسمى التيسير.
6. لا يُفسر الدليل المدعوم على أنه فشل.
7. لا جمع غير ضروري لبيانات خاصة أو حساسة.
8. لا استقصاء لإفصاحات الحماية من خلال أثر.
9. لا ادعاء بأن تجربة محدودة تثبت الجاهزية للإنتاج.
10. يحق للطفل التوقف في أي وقت.
