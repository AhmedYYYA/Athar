# ATHAR | أثر — Minimum Pilot Execution Kit

At each session location have access to:
- supported device/browser and power;
- approved ATHAR website baseline;
- participant code/session assignment list held under operator controls as applicable;
- Facilitator Quick Card;
- observer guide/checklist;
- session tracker;
- issue/defect tracker;
- safeguarding escalation contact/path;
- state reset procedure for shared devices;
- stop/pause procedure;
- one or two bilingual reflection prompts.

Do not add recording equipment, analytics, third-party AI tools or extra child-data collection merely for convenience unless separately approved within the pilot governance.
