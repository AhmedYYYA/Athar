# ATHAR | أثر — Pilot Execution One-Page Control

**Purpose:** Test safe usability, comprehension, judgement, safety behaviour and evidence interpretation of the 16-mission bilingual foundation.

**Current product:** bounded static web pilot; Arabic/English; ages 7–12; browser-local progress; no live AI, production accounts, centralized child records, ads or production analytics.

**Before any session:** approved participation process + child assent; participant code; correct language/age; supported device; clean state where required; facilitator briefed; safeguarding contact known.

**Adult behavior:** facilitate, do not co-answer. Observe first. Help navigation if needed. Ask “How do you know?” Hints are allowed and produce supported—not failed—evidence.

**Stop:** child asks; persistent material distress/confusion/fatigue; unnecessary sensitive disclosure; safeguarding concern; unsafe/blocking defect; supervision cannot be maintained.

**Record:** coded session metadata, observation codes and issue references only. No routine need for names, raw answers or private conversations.

**Severity:** S0 observation · S1 minor · S2 material · S3 critical/pause.

**Daily decision:** Continue · Mitigate · Pause flow · Pause pilot.

**Before full cohort:** complete readiness checklist + supervised shakedown; no open S3; every S2 owned/mitigated.

**Final decision:** GO · CONDITIONAL GO · REWORK · NO-GO, based on observed evidence and the production gap register.
