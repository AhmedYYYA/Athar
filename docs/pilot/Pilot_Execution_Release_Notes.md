## Added
A controlled operational layer for moving from an approved pilot design to supervised execution readiness: runbook, readiness and shakedown gates, RACI, bilingual facilitator material, minimal coded trackers, risk/severity controls, daily review, closeout and Go/No-Go decision structure.

## Not added
No changes to the child website, curriculum, missions, Passports, evidence logic, characters or browser-local state. No production accounts, identity/consent database, analytics, live AI, school cohorts or safeguarding case-management capability.

## Safety/privacy posture
Routine pilot analytics are pseudonymous/minimal by design. Safeguarding matters are routed to the operator's approved process. Stage 7 explicitly prevents a documentation package from being mistaken for authorization to begin child sessions.

## Gate
Merge requires GREEN repository CI. Real pilot execution requires the separate readiness checklist, external approvals and supervised shakedown.
