# ATHAR | أثر — Pilot Finding Taxonomy

Use consistent categories when synthesizing findings:

- **UX-NAV:** navigation/discoverability
- **UX-READ:** readability/layout
- **LANG-AR / LANG-EN:** language/localization
- **ACC:** accessibility/accommodation
- **TECH:** technical reliability
- **PED-COMP:** concept comprehension
- **PED-JUDG:** judgement/verification
- **PED-AGENCY:** child agency/authorship
- **SAFE-PRIV:** privacy behavior
- **SAFE-TRUST:** trusted-adult behavior
- **SAFE-TOOL:** tool-not-person understanding
- **EVID-SUP:** supported evidence interpretation
- **EVID-PASS:** Passport evidence usefulness
- **OPS:** facilitator/session operations
- **GOV:** governance dependency

A finding may have more than one category. Do not use the taxonomy to create personality, intelligence or risk scores for individual children.
