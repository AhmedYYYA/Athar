# ATHAR | أثر — Pilot Security Control Check

For the current static pilot:
- [ ] Public repository contains no real participant data.
- [ ] Completed trackers are stored only in the operator's approved location.
- [ ] No secrets/API keys are introduced into public client code.
- [ ] No unapproved analytics or third-party data collection is active.
- [ ] Shared-device state handling is understood.
- [ ] Sensitive incident communication uses approved channels, not public GitHub issues.
- [ ] Access to pilot records follows named operator roles.
- [ ] Device/browser updates and network restrictions do not create unsafe workarounds.

Any future backend/accounts/live-AI implementation requires a separate production security architecture and assessment; this checklist does not cover that future system.
