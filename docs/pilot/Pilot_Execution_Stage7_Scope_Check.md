# ATHAR | أثر — Stage 7 Scope Verification

Stage 7 is accepted only if repository comparison against its Stage 6 parent shows changes limited to:
- `docs/pilot/**` operational documentation/templates; and
- test/package configuration needed to validate those artifacts.

Any unexpected change to `index.html`, `learn.html`, `lesson.html`, curriculum data, mission data, CSS/JS child experience, Passport/evidence logic or character assets must be reviewed separately and removed from this stage unless explicitly authorized.

This protects the validated child product from being modified under an operations-documentation milestone.
