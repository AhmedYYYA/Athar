# ATHAR | أثر — Pilot Analysis Plan

## Questions
Analyze the pilot against the approved dimensions: usability, comprehension, judgement, safety behaviour and evidence interpretation.

## Segment before pooling
Where sample permits, inspect:
- ages 7–9 vs 10–12;
- Arabic-primary vs English-primary sessions;
- independent vs supported evidence context;
- device class when usability differs.

## Evidence sources
Use coded session records, structured observation checklist, defect/issues, reflection summaries, parent/educator structured feedback and the existing Passport evidence signals. Do not require raw child conversations.

## Interpretation rules
- report counts/rates only when denominators are clear;
- do not claim statistical generalizability from a small controlled pilot;
- distinguish absence of observed harm from proof of safety;
- distinguish successful mission completion from broad AI mastery;
- supported evidence is not failure;
- separate product friction from learning difficulty;
- identify baseline changes before combining observations.

## Output
The final analysis should feed `Pilot_Go_NoGo_Decision_Memo.md` and update `Pilot_vs_Production_Gap_Register.md`, with observed evidence clearly separated from recommendations and assumptions.
