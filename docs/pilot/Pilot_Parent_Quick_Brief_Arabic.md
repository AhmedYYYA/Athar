# أثر | ATHAR — إحاطة مختصرة لولي الأمر قبل الجلسة

أثر تجربة تعليمية تساعد الطفل على فهم الذكاء الاصطناعي واستخدامه بحكم ومسؤولية. **الطفل هو من يفكّر، والذكاء الاصطناعي أداة مساعدة وليس سلطة أو شخصاً.**

في النسخة التجريبية الحالية:
- المهام محددة وموجهة؛
- لا توجد دردشة مفتوحة غير محدودة مع الطفل؛
- لا توجد إعلانات؛
- التقدم محفوظ محلياً في المتصفح ضمن حدود النسخة التجريبية؛
- لا توجد حسابات أطفال إنتاجية أو ملفات مدرسية مركزية؛
- يمكن للطفل استخدام التلميحات، ويُسجل ذلك كدليل مدعوم وليس كفشل.

خلال الجلسة، يوجد إشراف بالغ وفق خطة التجربة. يستطيع الطفل طلب المساعدة أو التوقف في أي وقت. لا نحتاج في الملاحظات الروتينية إلى اسم الطفل أو إجابات خاصة أو محادثات شخصية؛ ويُفضّل استخدام رمز مشارك لأغراض التحليل.

أي موافقة أو حفظ بيانات أو إجراءات حماية رسمية تتبع العملية المعتمدة لدى الجهة المشغلة للتجربة، وليست وظيفة ضمن موقع أثر الحالي.
