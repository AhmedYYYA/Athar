# ATHAR | أثر — READ ME FIRST: Pilot Execution

If you are preparing to run ATHAR with children, do **not** begin with the session tracker.

1. Read `ATHAR_Pilot_Protocol.md`.
2. Complete `Pilot_Execution_Readiness_Checklist.md`.
3. Resolve `Pilot_Execution_Governance_Dependencies.md` with the actual operator/institution.
4. Appoint roles using `Pilot_Execution_Roles.md`.
5. Lock/test the exact website baseline.
6. Run site/device preflight and the fictional incident drill.
7. Brief/qualify facilitators.
8. Conduct the supervised shakedown.
9. Only after the shakedown gate, complete `Pilot_Launch_Decision_Record.md`.
10. Then run bounded sessions under the Runbook.

**Repository readiness is not child-pilot authorization.**
