# ATHAR | أثر — Pilot Readiness Package v10

**Status:** Staged for review  
**Product baseline:** Stage 5 / Pilot Readiness & System QA v9  
**Current build:** Static bilingual web/PWA pilot with deterministic reviewed missions, browser-local bounded progress, no live child chatbot, no accounts, no payments and no analytics backend.

## Purpose
This package prepares ATHAR | أثر for a controlled UAE-first usability and learning pilot with children aged 7–12, families and educators. It is an operational pilot package, not a claim of production-school readiness.

## Pilot principles
- The child remains the thinker; AI remains a supervised learning instrument.
- Arabic and English are equal pilot experiences.
- Children work through bounded, reviewed missions rather than unrestricted chat.
- Completion, independent evidence and supported evidence remain distinct.
- Hints are recorded honestly as supported evidence.
- Adults support safety, context and reflection without turning learning into surveillance.
- No raw child answers, private conversations or identifying information are required by the current product.
- Safety, wellbeing, personal information and high-stakes decisions return to a trusted adult.

## Readiness boundary
The current website is suitable for a **controlled observational/usability and foundational-learning pilot** once the operating organisation completes its own participant approval, parent/guardian consent, child assent, safeguarding, venue/device and legal/privacy arrangements. It must not be represented as an LMS, production school record, clinical/safeguarding system, or live-AI service.
