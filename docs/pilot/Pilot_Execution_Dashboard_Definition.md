# ATHAR | أثر — Pilot Control Dashboard Definition

If a dashboard is later built for the pilot operator, its minimum safe view should aggregate operational controls rather than profile children.

Recommended tiles:
- sessions planned/completed;
- Arabic vs English session count;
- 7–9 vs 10–12 session count;
- S1/S2/S3 open/closed issues;
- issue categories (NAV/LANG/ACC/TECH etc.);
- flows/missions affected by defects;
- daily continue/mitigate/pause status;
- baseline version;
- readiness/closeout gate status.

Do not show child names, leaderboards, generalized ability scores, raw answers, private conversations or safeguarding narratives. Stage 7 does not implement this dashboard; this definition only constrains any future pilot-operations implementation.
