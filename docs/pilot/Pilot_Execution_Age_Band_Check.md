# ATHAR | أثر — Pilot Age-Band Check

Sample ages 7–9 and 10–12 as distinct experience bands.

## Ages 7–9
- instructions remain short/concrete;
- required interaction does not depend on typing in the pilot;
- touch targets and text are readable;
- facilitator can support navigation without teaching answers;
- optional deeper explanation does not obstruct the core task.

## Ages 10–12
- core mission remains the same learning spine;
- optional deeper reasoning/terminology is available where designed;
- child can explain judgement/verification rather than merely select answers.

## Analysis
Do not silently pool findings when friction differs by age band. Record `age_band` in the minimal session tracker and treat age-related UX patterns as evidence about product design, not as labels about individual ability.
