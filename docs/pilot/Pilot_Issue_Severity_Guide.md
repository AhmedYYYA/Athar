# ATHAR | أثر — Pilot Issue Severity Guide

## S0 — Observation
No intervention required. Useful pattern or comment only.

## S1 — Minor
Friction exists but the child can continue safely and the learning task remains interpretable. Example: cosmetic spacing issue with no readability loss.

## S2 — Material
Meaningful impairment to usability, comprehension, localization, accessibility or evidence interpretation. A safe workaround may exist. Requires owner and mitigation before scale.

## S3 — Critical
Stop or pause condition. Includes a defect/control failure that creates material safeguarding/privacy risk, blocks safe use, causes serious accessibility exclusion in the intended pilot flow, materially misrepresents safety guidance, or prevents the approved supervision model from operating.

## Rules
- Severity is based on impact, not how easy the fix is.
- Repeated S1 issues may become S2 if cumulative friction materially affects the session.
- A safeguarding disclosure itself is not a software severity score; route it through the approved safeguarding process. S3 may apply to the **pilot control failure** associated with it.
- S3 product/control issues require explicit pause/resume authority and verification of relevant fixes.
