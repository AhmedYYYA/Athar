# ATHAR | أثر — Pilot Record Set

## Routine analytical set
- Pilot_Session_Tracker.csv
- Pilot_Issue_Tracker.csv
- Daily_Pilot_Control.csv
- Pilot_Risk_Register.csv
- Pilot_Execution_Change_Log.csv
- structured observation checklist/feedback permitted by the approved process

## Control records
- readiness/sign-off/launch decision;
- shakedown report;
- technical preflight;
- checkpoints;
- closeout checklist;
- Go/No-Go decision memo.

## Outside ATHAR analytical set
Any real-identity linkage, formal consent record, safeguarding case narrative or institution-required sensitive record should remain in the operator's approved system with appropriate access controls, unless a later production architecture explicitly implements and approves such capability.

This separation prevents the static ATHAR pilot repository from becoming an informal child-record system.
