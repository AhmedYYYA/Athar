# ATHAR | أثر — Pilot Closeout Checklist

## Records
- [ ] All planned/completed sessions reconciled.
- [ ] S2/S3 items reviewed and disposition recorded.
- [ ] Defect records linked to fixes/verification where applicable.
- [ ] Safeguarding/privacy routing records reconciled with the operator's approved process without duplicating sensitive narratives.
- [ ] Baseline changes, if any, documented.

## Analysis integrity
- [ ] Arabic and English findings reviewed separately before combined interpretation.
- [ ] Ages 7–9 and 10–12 reviewed separately before combined interpretation.
- [ ] Independent vs supported evidence interpreted as learning signals, not rankings.
- [ ] Product defects separated from pedagogy findings.
- [ ] Missing data and small samples are not presented as proof of equivalence or effectiveness.

## Governance
- [ ] Pilot record retention/deletion action initiated under the approved operator process.
- [ ] Access to pilot records reviewed.
- [ ] Production gap register updated.
- [ ] Any unresolved critical risk explicitly carried forward.

## Decision
- [ ] Success metrics reviewed against observed evidence.
- [ ] Go/No-Go decision memo completed.
- [ ] Technical review completed.
- [ ] Safeguarding/privacy review completed.
- [ ] Education/curriculum review completed.
- [ ] Final decision authority recorded GO / CONDITIONAL GO / REWORK / NO-GO.

The pilot is not closed merely because sessions have ended; closeout requires evidence reconciliation and a recorded decision.
