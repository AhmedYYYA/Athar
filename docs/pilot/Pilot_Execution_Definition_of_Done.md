# ATHAR | أثر — Stage 7 Definition of Done

Stage 7 is complete when the **repository execution package** is approved, CI is GREEN, and a locked milestone can be recovered. This means ATHAR has the operational documentation and control artifacts needed to prepare a real supervised pilot.

Stage 7 completion does **not** mean the real-world pilot has started, is legally approved, has completed consent/assent, or has demonstrated educational effectiveness.

The next transition after Stage 7 is not another website redesign. It is **Pilot Launch Authorization**, driven by the readiness checklist, named roles, external governance decisions, site/device preflight and successful shakedown.
