# ATHAR | أثر — Pilot Approval Matrix

| Gate | Evidence | Authority | Required before |
|---|---|---|---|
| Repository Stage 7 | GREEN CI + approved PR | Product owner | Lock Stage 7 |
| Technical baseline | Technical preflight + immutable SHA | Technical Lead / Pilot Lead | Shakedown |
| Governance | Consent/assent, safeguarding, data/site approvals | Operator/institution | Any child session |
| Facilitator readiness | Competency check | Pilot Lead | Facilitator runs session |
| Shakedown | Shakedown report; no open S3 | Pilot Lead + relevant leads | Planned cohort |
| Launch | Launch Decision Record | Named institutional/pilot authority | Controlled cohort |
| Mid-pilot continuation | Daily/checkpoint records | Pilot Lead | Continued operation after material issue |
| Closeout | Closeout checklist | Pilot Lead | Final analysis |
| Next phase | Go/No-Go memo + gap register | Final decision authority | Larger pilot/production phase |

A lower gate cannot waive a higher external governance requirement.
