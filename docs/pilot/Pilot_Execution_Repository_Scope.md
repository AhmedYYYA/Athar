# ATHAR | أثر — Repository Scope During Pilot

The GitHub repository may contain:
- public pilot website code/assets;
- non-sensitive pilot protocols/templates;
- blank minimal tracker schemas;
- QA tests and configuration-control documentation.

Do **not** commit completed child session trackers, participant-code linkage files, consent records, safeguarding records, private screenshots, or other real participant data to the public repository.

Completed pilot records must use the operator's approved storage/access arrangement outside this public code repository.
