# ATHAR | أثر — Bounded Session Script

Use as a guide, not a rigid interrogation script.

## Opening
**EN:** “Today you’ll try a few ATHAR missions. ATHAR is a learning tool, not a person. You do the thinking. You can ask for help or stop whenever you want.”

**AR:** «اليوم ستجرب بعض مهام أثر. أثر أداة للتعلّم، وليس شخصاً. أنت من يفكّر. ويمكنك طلب المساعدة أو التوقف متى أردت.»

## If navigation blocks progress
**EN:** “I can help you find the button, but I won’t choose the answer for you.”

**AR:** «يمكنني مساعدتك في العثور على الزر، لكنني لن أختار الإجابة بدلاً منك.»

## Neutral reasoning prompt
**EN:** “How do you know?” / “What would you check?”

**AR:** «كيف عرفت؟» / «ما الذي ستتحقق منه؟»

## If a hint is used
**EN:** “The hint is there to help. Now show me what you think.”

**AR:** «التلميح موجود للمساعدة. الآن أرني ما الذي تفكر فيه.»

## Closing
Choose one or two prompts from `Pilot_Reflection_Prompts.md`, thank the child, and end the bounded session. Do not extend the session simply to complete more missions.
