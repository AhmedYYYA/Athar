# ATHAR | أثر — Stage 7 Acceptance Criteria

Stage 7 can be locked when:
1. All execution-control documents and trackers in the package manifest exist and are internally consistent.
2. Repository regression/CI is GREEN with the Stage 7 integrity test included.
3. No Stage 7 change modifies curriculum, Passport/evidence rules, mission engine or public website behavior.
4. The package explicitly distinguishes repository readiness from authorization to run child sessions.
5. Participant tracking is pseudonymous/minimal by design and contains no required child-name field.
6. Safeguarding/privacy incidents are routed to the operator's approved process rather than turned into an ATHAR case-management system.
7. A pre-cohort shakedown gate and end-of-pilot Go/No-Go gate are defined.
8. Arabic facilitator/parent/educator operational briefs are present alongside English/bilingual material.

Actual pilot execution additionally requires completion of `Pilot_Execution_Readiness_Checklist.md`; Stage 7 merge alone does not satisfy external approvals.
