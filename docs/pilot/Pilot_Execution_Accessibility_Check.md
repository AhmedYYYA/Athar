# ATHAR | أثر — Pilot Accessibility Observation Gate

Automated/browser QA is necessary but does not replace observed accessibility during the pilot.

Before and during shakedown, check:
- visible keyboard focus where keyboard use applies;
- touch target usability on target devices;
- text readability at intended distance/zoom;
- no critical content hidden by viewport overflow;
- reduced-motion preference behaves safely;
- language/RTL changes do not break focus/order;
- contrast remains readable in actual device conditions;
- instructions are understandable without relying only on colour;
- any participant accommodation required by the pilot site is known before participation.

Record barriers using `ACC`. A material barrier for intended participants is S2 or S3 depending on impact; do not reinterpret exclusion as a child-performance finding.
