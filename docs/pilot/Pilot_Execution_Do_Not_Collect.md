# ATHAR | أثر — DO NOT COLLECT / لا تجمع

For routine ATHAR pilot analysis, do **not** collect merely because it is observable:

- child name / اسم الطفل
- personal phone/email / رقم الهاتف أو البريد الشخصي
- home address / عنوان المنزل
- health information / معلومات صحية
- family circumstances / ظروف عائلية
- raw private conversations / محادثات خاصة خام
- passwords/account credentials / كلمات المرور وبيانات الدخول
- unnecessary photos/video/audio / صور أو فيديو أو صوت غير ضروري
- diagnostic/personality labels / تصنيفات تشخيصية أو شخصية

Use a **participant code / رمز المشارك** and structured learning/usability observations.

If an approved safeguarding or institutional process requires information outside these routine pilot fields, handle it through that approved process—not by expanding the ATHAR analytical tracker informally.
