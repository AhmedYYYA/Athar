# ATHAR | أثر — Pilot Execution Readiness Checklist

Stage 7 is **execution-ready** only when every applicable critical item below is confirmed. This checklist does not itself grant legal, safeguarding or institutional authorization.

## Product baseline
- [ ] Approved milestone/commit recorded.
- [ ] Regression and browser QA GREEN on that baseline.
- [ ] Arabic and English homepage/Journey/mission entry manually sampled on representative devices.
- [ ] No unapproved product change introduced after baseline verification.

## Governance
- [ ] Pilot Lead named.
- [ ] Safeguarding Lead named and reachable.
- [ ] Technical Lead named.
- [ ] Evidence/data owner named.
- [ ] Parent/guardian consent process approved by operator.
- [ ] Child assent process approved by operator.
- [ ] Institutional/site authorization complete where applicable.
- [ ] Data handling/storage location and retention approach approved outside the product.

## Operations
- [ ] Participant-code convention prepared.
- [ ] Facilitators briefed using `Facilitator_Quick_Card.md`.
- [ ] Observation checklist ready.
- [ ] Session/defect/incident logs ready.
- [ ] Supported device/browser list communicated.
- [ ] State reset procedure understood.
- [ ] Stop criteria understood.
- [ ] Daily control review scheduled.

## Evidence discipline
- [ ] Independent vs supported evidence explained to adults.
- [ ] No raw child answers required for routine analysis.
- [ ] Product defects and pedagogy observations recorded separately.
- [ ] Arabic/English findings can be separated.
- [ ] Ages 7–9 / 10–12 findings can be separated.

## Shakedown gate
Before the planned 40–60-child cohort:
- [ ] Conduct a small supervised shakedown.
- [ ] Review all S2/S3 findings.
- [ ] Verify any critical fix through regression/browser QA.
- [ ] Pilot Lead records proceed / mitigate / pause decision.

## Exit preparation
- [ ] Success metrics reviewed before data collection begins.
- [ ] Pilot-vs-production gap register current.
- [ ] Go/No-Go decision memo template ready.
- [ ] Decision authority identified.
