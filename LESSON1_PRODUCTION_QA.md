# ATHAR Lesson 1 — Production QA Gates

## Gate 1 — Functional
- [ ] Stages 00–09 complete in controlled sequence.
- [ ] Required mastery interactions block progression until resolved.
- [ ] Corrective feedback uses a different explanation/context rather than repeated guessing.
- [ ] Age 7–9 pathway requires no typing.
- [ ] Age 10–12 exposes optional deeper reasoning without changing core curriculum.

- [ ] Companion state persists: Hamdan / Hessa / No companion.

## Gate 2 — Educational & Child Safety
- [ ] Approved Stage 00–09 pedagogy is source of truth; concept-board wording does not override it.
- [ ] AI is consistently described as a tool, not a person/authority.
- [ ] Machine learning is not presented as all AI.
- [ ] Deterministic exercises are visibly labelled simulation where relevant.
- [ ] Blind trust and blanket distrust both receive corrective feedback.
- [ ] Privacy failure requires corrective demonstration before Passport evidence.
- [ ] Health/safety scenario requires trusted-adult escalation.
- [ ] Competency-critical companion hints record supported rather than independent demonstration.
- [ ] No emotional-dependency or exclusivity language from companions.
- [ ] No psychometric/personality/intelligence/emotional inference.

## Gate 3 — Visual & Brand
- [ ] ATHAR approved mark only; Arabic أثر retains ث with three dots.
- [ ] Approved Hamdan/Hessa visual identity only; no character redesign.
- [ ] Companion remains secondary to ATHAR experience.
- [ ] Mobile-first visual hierarchy matches approved high-fidelity baseline.
- [ ] No coins, streaks, rankings or addictive reward loops.
- [ ] Feedback does not use punitive visual treatment as the default learning pattern.

## Gate 4 — Accessibility / Performance / Security
- [ ] Keyboard-only navigation through all controls.
- [ ] Visible focus indicator meets contrast needs.
- [ ] Meaning never depends on colour alone.
- [ ] Reduced-motion preference respected.
- [ ] Responsive at 320px through large desktop.
- [ ] Touch targets suitable for children/mobile use.
- [ ] Accessible names/roles/states for interactive controls.
- [ ] No live AI, auth, payments or real child data in this build.
- [ ] No external analytics/ad trackers.
- [ ] Local storage contains only bounded demo state.
- [ ] No secrets/API keys/client credentials.
- [ ] Asset loading and JS failures degrade safely.

## Release rule
Do not merge this branch to `main` until all four gates are complete, visual regression is reviewed, and explicit user approval is recorded.
